# Generals Mobile V10 — حملة متوازنة

نسخة محسنة من V9. تضم 12 مهمة بتدرج الصعوبة وموازنة الموارد وسرعة إنتاج الكمبيوتر، مع زيادة دخل اللاعب وتقليل الهجوم المبكر.

## المهمات
1. تأمين الشاطئ
2. خط الإمدادات
3. الدفاع عن القاعدة
4. حصار الصحراء
5. عملية الفجر
6. العاصفة الرملية
7. الحدود الملتهبة
8. الاختراق المدرع
9. القلعة المحصنة
10. عملية البرق
11. الضربة الأخيرة
12. معركة القيادة

ملاحظة: عناوين المهمات وأهدافها القصصية تختلف، لكن شرط الفوز الحالي يظل تدمير مقر العدو. الأهداف الإضافية لم تتحول بعد إلى شروط إلزامية.

تعمل المعارك برسومات Canvas ثنائية الأبعاد؛ ملفات GLB مرفقة لكنها ليست معروضة داخل اللعبة. اللعب الجماعي يحتاج خادماً منشوراً.
